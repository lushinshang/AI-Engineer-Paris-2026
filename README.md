# AI Engineer Paris 2026｜思想煉金報告

AI Engineer Paris 2026 大會（2026/9/23-24，法國巴黎）兩天演講的深度筆記報告：Day 1 開幕場 3 講、Day 2 Main Stage 12 講，逐場包含講者背景、思想煉金導讀、批判性思考、跨議程交叉分析，以及 AI 生成的資訊圖表。

線上閱讀：https://lushinshang.github.io/AI-Engineer-Paris-2026/

## 200 字介紹

這份報告把兩天 15 場演講的 YouTube 逐字稿，依講者轉場語句切分還原成個別場次，逐場產出結構化筆記——核心洞見（附反直覺/可遷移/行動改變性標註）、關鍵論點、實務案例、批判性思考（含具名反例與適用邊界）、角色化行動建議。每場的講者背景經 WebSearch 查證，查無資料處如實標註。Day 1、Day 2 各自另有跨議程交叉分析，用 Mermaid 圖呈現不同講者間的觀點收斂與分歧。內容經深度導讀改寫與編輯審查潤飾，讀者對象設定為台灣中型組織的 IT／資安／AI 應用負責人。
